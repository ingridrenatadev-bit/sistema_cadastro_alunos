# Sistema de Cadastro de Turma

Este é um sistema que gerencia uma turma de até 30 alunos, com diversas funcionalidades como cadastro, listagem, barra de pesquisa, verficação de aprovados/recuperação/reprovados e sair. Estou unindo meu conhecimento em array, struct, validação e funções em C.

## 🚀 Funcionalidades: 

- **1 - Cadastro do aluno** 
- **2 - Listagem de todos os alunos (nome + média + situação atual)** 
- **3 - Busca aluno por nome**
- **4 - Verificação da quantidade de alunos aprovados, em recuperação e reprovados** 
- **5 - opção de sair do sistema**

## 🛠️ Tecnologias Utilizadas
- Linguagem C Pura (Padrão ISO)
- Gerenciamento Manual de Fluxo de Memória
